## Завдання 2. Обчислення визначеного інтеграла методом Монте-Карло

Досліджувалось обчислення визначеного інтеграла функції $f(x) = x^2$ на інтервалі $[0, 2]$.

### 1. Еталонні значення
* **Аналітичний розрахунок (формула Ньютона-Лейбніца):**
  $$\int_{0}^{2} x^2 \, dx = \left. \frac{x^3}{3} \right|_{0}^{2} = \frac{8}{3} - 0 = 2.66666667$$
* **Функція `scipy.integrate.quad`:** `2.66666667` (оцінка абсолютної похибки становить $2.96 \times 10^{-14}$).

### 2. Результати методу Монте-Карло залежно від кількості випадкових точок ($N$)

* **$N = 1\,000$:** результат `2.58400000` (абсолютна похибка: `0.08266667`, відносна похибка: `3.1000%`)
* **$N = 10\,000$:** результат `2.61920000` (абсолютна похибка: `0.04746667`, відносна похибка: `1.7800%`)
* **$N = 100\,000$:** результат `2.63720000` (абсолютна похибка: `0.02946667`, відносна похибка: `1.1050%`)
* **$N = 1\,000\,000$:** результат `2.66404000` (абсолютна похибка: `0.00262667`, відносна похибка: `0.0985%`)

### Висновки

1. **Збіжність:** результат Монте-Карло збігається з `quad` та аналітичним значенням. Чим більше точок $N$, тим ближче він до істинного $2.6667$.
2. **Похибка:** вона зменшується пропорційно до $\frac{1}{\sqrt{N}}$. Щоб підвищити точність у 10 разів, потрібно у 100 разів більше точок.
3. **Коли що використовувати:** для простих одновимірних функцій, як $f(x) = x^2$, `scipy.integrate.quad` швидший і точніший. Монте-Карло краще підходить для багатовимірних інтегралів і складних областей, де класичні методи працюють погано.
